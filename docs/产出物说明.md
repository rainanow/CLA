# 产出物说明

所有产出在 `<out>/` 下。数据源统一是 `results/<日期>.json`，改产出样式时只需改 Stage 3 脚本，不必重跑 Stage 2。

## 1. results/&lt;日期&gt;.json（每日评分，数据源）

```json
{
  "date": "2025-06-15",
  "intensity": 3,                     // 情绪浓度 1-5
  "polarity": "正",                    // 正 / 负 / 中 / 混合
  "polarity_note": "整体温馨，晚间担忧构成轻微负向",
  "low_confidence": false,             // 信号不足时为 true
  "day_summary": "当天概要，一两句话",
  "events": [
    {"time": "09:58", "level": "小", "title": "事件短标题", "desc": "一两句描述"}
  ],
  "evidence": ["支撑评分的关键消息原文引用，最多5条"],
  "_usage": {"in": 3518, "out": 313, "cache_hit": 0, "sec": 2.4},
  "_day_msgs": 195
}
```

字段语义：

| 字段 | 说明 |
|------|------|
| `intensity` | 情绪浓度。每天必有值，与事件等级正交 |
| `polarity` | 极性。`混合`仅在正负双方都强且拉扯时使用 |
| `events[].level` | 事件等级（大/小）。平静但重要的事是"大"，热闹但琐碎的事是"小" |
| `low_confidence` | 图片盲区或信号不足导致判断不确定 |

## 2. 输出/事件索引表.md 与 .csv

全量事件的表格索引。列：日期 / 时间 / 等级 / 事件 / 描述（仅 csv）/ 当日浓度 / 极性。

- `.csv` 用 `utf-8-sig` 编码，Excel 双击可正常显示中文
- 用途：筛选（例如"所有大事件"）、统计（例如"每年冲突次数"）、交叉分析

## 3. 输出/事件/&lt;年&gt;.md

按年组织的事件文档，每天一段：日期标题（含量与极性）、当日概要、事件明细。用于连续阅读与人工复核。

## 4. 输出/可视化.html

单文件、无外部依赖，双击即开：

- **日历热力图**：按年月铺开，颜色 = 极性（正红/负绿/混紫/中灰），深浅 = 浓度 1-5，黑框 = 含大事件，灰色 = 无聊天。悬停显示当日评分、事件、概要
- **大事件时间轴**：大事件按时间散布在轴两侧（正向在上、负向在下），刻度按季度。悬停显示事件名
- **统计面板**：天数、平均浓度、各档分布、极性分布、含大事件天数

改样式：编辑 `pipeline/build_outputs.py` 里的 `HTML_TEMPLATE`，然后 `python run_all.py --out <目录> --only stage3`。

## 5. data/days/&lt;日期&gt;.json（清洗后日数据）

清洗并折叠刷屏后的当日消息，LLM 实际看到的输入。排查"某天为什么打这个分"时看这个文件。

## 6. 常见用途

| 想做什么 | 用什么 |
|---------|--------|
| 找出所有重大冲突 | 索引表按 等级=大 且 极性=负 筛选 |
| 看情绪整体的时间趋势 | 可视化热力图的颜色深浅变化 |
| 研究某段时间发生了什么 | 事件/&lt;年&gt;.md 连续阅读 |
| 复核某天评分是否合理 | results 的 evidence 字段 + data/days 原文 |
| 喂给另一个 AI 做深度分析 | 索引表 csv + 事件文档 md（结构化后体积小、塞得下） |
